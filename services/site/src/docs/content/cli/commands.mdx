---
title: "Commands"
description: "Reference for the ofecode command line."
---

Every command accepts `--help` for its full flag list, for example `ofecode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ ofecode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: OfeCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: ofecode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ ofecode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ ofecode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ ofecode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ ofecode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ ofecode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ ofecode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ ofecode run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `ofecode session list` includes it, and you can open it by ID.

```bash
$ ofecode run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ ofecode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ ofecode mini
```

Continue the last session.

```bash
$ ofecode mini --continue
```

Start with a model and an initial prompt.

```bash
$ ofecode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ ofecode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ ofecode mini --help
```

## session

Manages sessions.

```bash
$ ofecode session list
```

Limit the list and print JSON.

```bash
$ ofecode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ ofecode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ ofecode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ ofecode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ ofecode session import session.json
```

Import into a specific directory.

```bash
$ ofecode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ ofecode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ ofecode auth list
```

List them as JSON.

```bash
$ ofecode auth list --format json
```

Log in to a provider.

```bash
$ ofecode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ ofecode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ ofecode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ ofecode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ ofecode auth export anthropic > credentials.json
$ ofecode auth import credentials.json
```

View all subcommands and flags.

```bash
$ ofecode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ ofecode mcp list
```

Add a remote server.

```bash
$ ofecode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ ofecode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ ofecode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ ofecode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ ofecode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ ofecode mcp logout sentry
```

View all subcommands and flags.

```bash
$ ofecode mcp --help
```

## plugin

Manages plugins.

```bash
$ ofecode plugin list
```

Include built-in server plugins.

```bash
$ ofecode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ ofecode plugin add @example/opencode-tui
```

Check package plugins for updates.

```bash
$ ofecode plugin check
```

Update package plugins.

```bash
$ ofecode plugin update
```

Remove a plugin from global configuration.

```bash
$ ofecode plugin remove @example/opencode-tui
```

View all subcommands and flags.

```bash
$ ofecode plugin --help
```

```bash

```




## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ ofecode serve
```

Bind to all interfaces on a fixed port.

```bash
$ ofecode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ ofecode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ ofecode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ ofecode pair
```

Use an external URL in the links.

```bash
$ ofecode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ ofecode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ ofecode pair --remote --yes
```

View all subcommands and flags.

```bash
$ ofecode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ ofecode service start
```

Restart it.

```bash
$ ofecode service restart
```

Show its status.

```bash
$ ofecode service status
```

Stop it.

```bash
$ ofecode service stop
```

Read a setting.

```bash
$ ofecode service get hostname
```

Set a setting.

```bash
$ ofecode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ ofecode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ ofecode service set env OPENCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ ofecode service unset hostname
```

View all subcommands and flags.

```bash
$ ofecode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ ofecode reload
```

## api

Makes a request to the running server.

```bash
$ ofecode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ ofecode api session.list --param limit=10
```

Send a JSON body.

```bash
$ ofecode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ ofecode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ ofecode api --help
```

```bash
$ ofecode acp
```

View all subcommands and flags.

```bash
$ ofecode acp --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ ofecode debug agents
```

List configuration sources.

```bash
$ ofecode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ ofecode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ ofecode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ ofecode debug paths
```

Print a single path.

```bash
$ ofecode debug paths db
```

View all subcommands and flags.

```bash
$ ofecode debug --help
```

## upgrade

Upgrades OfeCode to the latest or a specific version. Alias: `update`.

```bash
$ ofecode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ ofecode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ ofecode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls OfeCode. Session data, configuration, and
state are not removed.

```bash
$ ofecode uninstall
```

Preview what would be removed.

```bash
$ ofecode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ ofecode uninstall --help
```
